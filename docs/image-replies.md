# 指定指令图片回复

适用于 Myrinbot Bot **0.6.22**。由服主选择哪些群内指令回复渲染成图片，其他消息继续使用文字。OneBot 11 和 QQ 官方机器人均有对应发送适配；图片在本机生成，无需外部图床或浏览器引擎。

## 配置与预览

1. 使用服主账号登录管理面板，进入「自动化 → 消息与事件 → 指定指令的图片回复」。
2. 启用图片渲染，在「转图片的指令」每行填写一个指令。也可点击常用指令按钮添加。
3. 点击「保存全部设置」，设置立即生效。未启用时，填写名单也不会改变原有回复方式。
4. 展开「排版预览」，输入指令名称和回复文字，点击「生成预览」。默认「使用下方示例文字」，可以先查看排版。
5. 要查看服务器实际效果，在「预览服务器」选择一台已保存的服务器。「在线」「状态」使用所选服务器的真实数据，其他指令仍使用下方文字。预览只在面板显示，不发送 QQ，不保存配置，也不会把主配置标记成已修改。

名单示例：

```text
在线
状态
帮助
我的绑定
执行 在线检查
```

基础指令按名称匹配，带参数时填写指令名，例如 `绑定`；`help` 和 `/help` 按 `帮助` 处理。预设控制台指令填写完整 `执行 命令名`，其提交提示与游戏端回传结果都使用相同设置。扩展指令填写扩展定义的命令名；关键词回复填写完整关键词。名单对所有服务器生效，区分其他文字大小写。

图片回复只改变显示形式，沿用关联群、管理员、绑定和插件权限检查。普通群服聊天、游戏通知、定时公告、故障提醒及私聊登录确认保持文字。修改后改回原值会清除未保存提示；预览不会清除已有的真实设置草稿。

## 图片样式与服务器数据

「在线」「状态」采用整幅原创冬日插画背景，叠加白色大标题、细白边与半透明毛玻璃卡片。右上数字框显示在线人数，下方三项统计展示服务器数量、更新时间和连接状态；每台服务器使用独立卡片，玩家以带名字首字头像的标签展示。内容来自当前群关联服务器的真实数据；服务器离线时不展示之前的玩家名单。名字首字头像由本地生成，不依赖游戏皮肤服务。

其他被指定转图的指令使用同风格毛玻璃文字卡片，显示原有回复内容。此次样式调整仅影响指令回复图片，管理面板界面保持原样。插画随程序内置，无网络依赖；已有的指定指令名单与开关继续生效，无须新增配置。

## 排版与发送

- 本地生成 PNG，使用随包提供的 Noto Sans SC 字体，支持中文、换行和长行自动折行；服务器简报与文字简报按指令自动选择。
- 单次回复最多 3500 个字符、4 页，每页图片不超过 2 MiB。超过排版边界或含字体不支持的字符时回退原有文字发送方式，原有文字长度限制仍适用。
- OneBot 发送 Base64 图片消息段，不把回复文字作为 CQ 码执行，不需要协议端读取 Bot 机器上的文件。
- QQ 官机先调用群文件上传接口，再以 `msg_type=7` 与 `file_info` 引用图片；优先附带有效消息引用和递增序号。需要 QQ 平台允许图片发送，并受被动回复次数、有效期、主动发送权限和额度约束。群内仍需先 @机器人。
- 渲染失败或首张图片被接口明确拒绝时回退文字。网络超时、连接中断或已经发送部分页面后，不重放整段回复；分页发送中关闭功能会停止后续页面。

排版器只处理文字，不执行 HTML / JavaScript，不解析 Markdown 图片或 CQ 图片，不访问回复中的网址。预览接口仅服主可用，图片只在内存中处理，不提供公开图片读取地址。

## 依赖与验证范围

安装器或升级器通过 `requirements.lock.txt` 安装 Pillow **12.3.0**。字体以可逆压缩形式嵌入 Python 模块，原始字体保持不变，兼容已部署的升级器路径规则；来源和许可见 [第三方声明](https://github.com/AlancoSage/StarBridge/blob/main/THIRD_PARTY_NOTICES.md) 与 [字体许可](noto-font-license.md)。

已通过本地中文排版、分页与边界、OneBot 消息段、官机模拟上传与引用、指令选择、异步执行结果、失败回退、权限和连接切换检查；未使用真实 QQ 账号或腾讯应用完成图片投递实测。上线后按自己的协议端或腾讯应用权限验收。
