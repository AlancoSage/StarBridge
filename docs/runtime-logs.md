# 实时运行日志

VexBot **0.6.36** 起，服主可在 **活动 → 运行日志** 查看终端式日志。页面汇总当前进程捕获的 Python 运行日志、错误堆栈，以及连接、插件、配置和玩家管理等业务记录。

## 查看与筛选

- 按等级、来源和关键词组合筛选。等级使用不同颜色，时间、来源与消息分列显示；多行异常保留换行。
- 日志页可见时，每秒请求新增记录；离开页面或切换到后台标签时暂停请求。
- 点击暂停可冻结当前视图，继续后补取缓存中的新增记录。滚动到底部后跟随新日志，上翻阅读时保留当前位置，可点击回到最新。
- 选择字号和换行方式，或展开为全屏阅读；按 `Esc` 退出展开。
- 复制或下载当前筛选结果。清空仅清除当前浏览器视图，不删除数据库中的业务记录，也不清空其他浏览器的日志。

日志读取沿用服主权限，普通团队账号不能访问。日志可能包含玩家名称及业务内容，分享前请自行检查；已识别的密码、令牌及授权头会被遮盖。

## 保留范围

当前进程最多缓存 **1000 条**，单条最多 **8192 字符**。启动时载入最近 **200 条**历史业务记录，页面首次最多读取 **500 条**，随后按游标增量更新。程序运行日志保存在有界内存缓存中；重启后重新开始，数据库中的业务审计记录按原规则保留。

暂停过久或断线期间缓存被覆盖时，页面会提示记录不完整并显示仍可读取的日志；服务重启后也会识别新的日志实例。请及时复制或下载需要保留的排查记录。

程序日志来自主进程与 `starbridge` 模块的 Python `logging` 记录，业务记录来自 VexBot 的审计事件。页面按程序当前日志级别收集记录，筛选 `DEBUG` 不会自动打开调试级别。不会读取任意磁盘日志文件，也不会改变 Python 日志级别、数据库结构或原有日志输出。

## 连接异常

临时网络错误会显示重试状态并逐步延长重试间隔；登录失效或权限不足时停止请求。重新登录，或使用页面的重新载入操作恢复。日志请求失败不会影响机器人和游戏联动。

## 管理接口

`GET /api/logs` 需要服主管理 Bearer 令牌或服主登录会话，响应禁止缓存。查询参数：

| 参数 | 说明 |
| --- | --- |
| `after` | 上次返回的非负整数游标，首次可省略 |
| `instance` | 上次返回的 `instance_id`，用于识别进程重启 |
| `limit` | 每次 1–500 条，默认 500 |

返回包含 `instance_id`、`cursor`、`oldest_cursor`、`entries`、`capacity`、`truncated`、`reset`、`levels` 和 `capture_level`。每条记录包含 `id`、`time`（Unix 秒）、`level`、`source` 和 `message`。使用返回的最后记录游标继续读取；`truncated` 表示所需旧记录已超出缓存，`reset` 表示日志实例已变化。接口不支持删除日志或修改日志等级。
