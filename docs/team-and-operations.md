# 团队权限与运行维护

## 多管理员

服主与团队成员都使用自己的用户名和密码登录。首次尚无服主账号时，在登录页点击独立的「创建服主账号」，用本机 `config.toml` 中的 `app.admin_token` 完成首次授权，设置服主用户名和密码。已有团队账号可直接登录，权限保持原设置。

服主登录后，在「设置 → 管理员与权限」创建团队成员的独立账号。名称为 3–32 位字母、数字、下划线或短横线，密码为 10–128 位。预设包含管理员、审核员、观察员，也可分别勾选权限。`app.admin_token` 继续供首次授权和兼容管理 API 使用，不作为日常登录密码。

| 权限 | 可操作内容 |
| --- | --- |
| `status.read` | 运行概览，团队账号必选 |
| `players.manage` | 玩家档案、实际游戏操作与账号绑定 |
| `whitelist.review` | 查看、代提交、审核白名单申请 |
| `plugins.manage` | JSON 插件安装、设置、更新、回退和权限 |
| `schedules.manage` | 内置定时任务插件启停、任务管理及手动执行；动作授权由插件管理权限调整 |
| `monitoring.manage` | 故障记录、已知晓标记和群提醒设置 |
| `stats.read` | 服务器统计和进退服记录 |
| `stats.manage` | 启停统计采集及保留时间 |
| `backups.manage` | 创建、查看和删除备份，修改保留规则 |
| `diagnostics.run` | 查看连接诊断，手动检测 SMTP 与公开官网 API |
| `tickets.manage` | 回复工单、内部备注、状态及提交额度设置 |
| `sanctions.manage` | 创建、撤销和重试跨服处罚 |

主程序配置、注册/SMTP/游戏登录设置、官网接入、其他管理员管理、程序重启、备份下载与恢复均仅服主可用。备份包含密钥，团队的备份管理权限不包括下载和恢复。未获授权的 API 返回 403；接口在后端鉴权，隐藏页面不是权限边界。无玩家权限的运行概览不返回绑定、IP、游戏管理记录或管理日志。

Bot 更新、回退及配置导入/导出也只允许服主操作。工单与跨服处罚采用独立权限，按团队职责分别授予。

团队成员使用各自的用户名和密码登录。密码使用 PBKDF2 哈希，登录计算在后台线程并有并发/持久限流。会话最多 8 小时，访问令牌仅保存在当前页面内存中；刷新后需重新登录。修改账号权限、密码、启停或删除账号会撤销已有会话。恢复备份后管理会话也撤销。创建和变更账号以及管理操作记录在日志中，不记录密码或访问令牌。

## 故障提醒

「活动 → 故障提醒」监测 QQ 连接、配置服务器的桥接心跳和实际 SMTP 邮件结果。默认启用面板监测，启动宽限 30 秒，每 5 秒检查；配置过但从未连接的服务在宽限过后同样显示异常。游戏失联表示心跳缺失，不等于确认游戏进程已关闭。

相同故障持续存在时只产生一条开放记录，恢复后标记已恢复；下一次故障生成新记录。标记已知晓不会伪造恢复状态。保存最多 500 条已恢复历史，页面显示最近 100 条。邮件只记录通用异常，不向提醒中附加邮箱、QQ、密码或验证码。

群提醒默认关闭。启用后填写最多 10 个群号，机器人需在对应群内；异常汇总只发送一次，发送失败后至少间隔一分钟再重试。QQ 断开时无法通过 QQ 即刻通知，恢复连接后可以发送仍未解决的故障。邮件恢复依赖下一次实际邮件发送成功，不进行外部探测。

## 服务器统计

「活动 → 服务器统计」提供最近 24 小时、7 天、30 天的在线趋势、每日活跃人数及最近 100 条进退服记录。默认每分钟采样，保留 30 天，可关闭采集或设置 1–90 天。页面统计最多每 30 秒更新一次，隐藏标签页暂停刷新；曲线为无持续动画的 SVG，不使用 Canvas、WebGL 或外部图表库。

趋势按时间区间计算每台服务器的平均在线人数，再合计；断连记录为缺失，不伪造 0 人。每日活跃按 UTC 日期统计实际观测到的不同游戏身份，同一 UUID 在多个服务器去重；缺少 UUID 时使用玩家名，身份信息完善时可能影响去重，因此这些是观测指标，不用于收费或处罚。数据从开始采集后累积，不从旧日志推测历史。进退服事件按桥接事件 ID 去重，最多保留 10000 条并按天数清理。

管理员、运行设置、故障历史、统计和插件版本记录都保存在 SQLite 数据库，随 Bot 数据备份保存。旧版备份没有这些表时，恢复后自动创建空表并使用默认设置。独立官网源码继续单独备份。
