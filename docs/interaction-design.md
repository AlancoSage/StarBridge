# 交互设计说明

VexBot 面向 Minecraft 社群的日常管理，围绕玩家自助、团队协作与社区运维组织功能。通用的聊天、账号绑定和白名单能力使用既有协议与明确的身份校验。

## 固定服务器操作

远程指令以一台服务器为单位编辑。每个指令保留群内命令名与完整控制台内容，卡片直接展示群内用法、目标服务器和固定执行内容，便于保存前核对。群内用法仍是 `执行 命令名`，复制用法不会提交任务；实际执行只允许配置中的机器人管理员，游戏端再次检查白名单。

## 文字问答

关键词回复采用独立问答编辑器，每条问答分别填写「收到这句话」与「发送这段文字」。本地检查只匹配当前草稿并展示文字，不发送消息或改变插件状态；实际群消息仍遵守插件开关、权限及内置命令优先级。回复保持纯文字，不把问答条目作为服务器操作或图片模板。

## 声明式消息规则

导入的扩展使用 VexBot JSON 格式，显式声明事件、文字模板、设置项和版本。使用者在启用前检查权限；卡片保留作者与版本信息。规则文件格式与具体限制见 [插件开发文档](plugin-development.md)。

## 来源与后续维护

交互差异不能代替来源核对。修改时保留原有版权声明、第三方许可证和 Git 历史；新增外部代码或素材时记录实际来源与授权。此文说明当前产品选择，不是对全部历史源码原创性或版权合规的鉴定。
