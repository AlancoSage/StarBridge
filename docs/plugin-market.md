# 插件市场

VexBot **0.6.35** 起，在 **扩展 → 插件市场** 浏览并安装适用于机器人主程序的消息规则插件。市场与「插件管理」使用同一套插件、权限、设置和版本记录。

## 浏览和安装

1. 搜索插件名称、说明或命令，或按分类和安装状态筛选。
2. 打开插件详情，查看功能说明、触发命令、能力与更新说明。
3. 点击安装。安装成功后，进入「插件管理」，修改插件设置并检查权限。
4. 启用插件，在已关联的 QQ 群中测试它声明的命令。事件通知需要游戏端连接。

安装和更新后插件均保持停用，不会立即发送群消息。每个插件的设置单独保存，无需点击主配置的「保存全部设置」。安装需要服主账号或具备 `plugins.manage` 权限的团队账号。

## 首批精选插件

| 插件 | 触发方式 | 用途 |
| --- | --- | --- |
| 群规公告 | `群规` | 回复可配置的社区规则与入群须知 |
| 服务器地址卡 | `服务器地址` | 展示 Java、基岩版连接地址和入服说明 |
| 在线快照摘要 | `在线摘要` | 展示当前关联服务器最近上报的连接状态、人数和玩家列表 |
| 个人绑定名片 | `身份名片` | 查询发起者在当前服务器绑定的游戏名称 |
| 入退服问候 | 游戏入退服事件；`通知说明` 查看用法 | 发送可配置的入退服文案 |
| 常见问题手册 | `常见问题` | 回复服主维护的新手指南和求助入口 |

离线服务器的在线摘要可能保留上次快照，请结合桥接连接状态查看。地址卡由服主填写，单个插件实例共用地址；内置进退服通知与自定义问候同时启用时会分别发送。

## 目录与更新

当前目录是随 VexBot 分发的精选规则插件，本机离线也可浏览和安装。升级 VexBot 后会获得新版目录；「重新载入」刷新当前实例的插件安装状态，不会从第三方网站下载插件。

已安装的插件与目录中已知的历史包一致，且目录提供可比较的较新版本时，市场提供更新。更新保留兼容设置和原有权限，保存旧版本供回退，然后保持停用；请检查设置后再次启用。在「插件管理 → 版本与回退」查看旧版本并回退。

相同版本内容不同、未知历史包、无法比较版本号或本地版本更新时，市场显示为本地版本，不直接覆盖。需要自行处理时，继续使用插件管理的 JSON 导入与版本回退功能。

目录随软件分发并校验包摘要，安装接口仅接受目录内的插件 ID；不会执行 Python、JavaScript 或任意外部下载。规则执行仍遵循已有的群关联、能力授权、身份范围和消息冷却。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 安装后没有回复 | 到「插件管理」配置并启用，确认 QQ 连接、关联群和触发命令 |
| 插件状态已变化 | 重新载入市场，核对最新状态后再操作；不会自动重试安装 |
| 无权访问 | 由服主授予团队账号「插件管理」权限 |
| 插件状态文件损坏 | 根据页面提示修复或恢复 `data/plugin-state.json` 后重启；市场保持只读 |
| 已安装 30 个外部插件 | 停用并移除不再需要的插件后再安装 |
| 想编写自己的插件 | 阅读[插件开发文档](plugin-development.md)，保留原有 JSON 导入方式 |

## 管理接口

所有接口需要管理 Bearer 令牌或具有 `plugins.manage` 权限的团队会话，响应禁止缓存。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/extension-market` | 读取目录、分类、包摘要及当前安装状态 |
| POST | `/api/extension-market/{id}/install` | 安装目录插件，默认停用 |
| POST | `/api/extension-market/{id}/upgrade` | 更新目录插件，保留兼容设置与权限并保持停用 |

写入正文为 `{ "revision": "...", "catalog_revision": "...", "sha256": "..." }`，三个值均来自最近一次目录响应。接口不接受插件定义、下载 URL 或额外字段。安装状态或摘要发生变化时拒绝旧请求；先重新读取并核对再操作。
