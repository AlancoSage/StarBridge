# 消息同步

适用于 Myrinbot Bot **0.6.20** 与 Paper / Spigot / Folia 游戏插件 **0.5.3**；模组服需安装对应版本的游戏端。

## 用途

把 QQ 群里的普通文字发送到 Minecraft 聊天，把游戏聊天发送到关联群，并按需发送玩家进退服通知。群与游戏的文本都有来源标记，便于成员识别发言者。

当前为文本联动。群图片在支持的消息段格式下显示为 `[图片]` 提示，不传送图片本体，也不生成聊天图片。

## 使用前提

- Myrinbot 主程序、OneBot 11 实现端与游戏端都已启动，总览显示 QQ 与目标游戏服连接正常。
- 在「接入空间 → 服务器列表」配置了目标群。每个群只能关联一台服务器，一台服务器可关联多个群。
- 机器人可以在关联群接收和发送消息。
- 启用游戏登录时，玩家先登录；未登录状态下的游戏聊天受限制。

基础同步不要求先绑定。绑定后，QQ 到游戏的发言显示绑定玩家名；未绑定时优先使用群名片，再使用昵称。

## 面板操作步骤

1. 进入「接入空间 → 服务器列表」，在目标服务器的「关联 QQ 群」填写群号，每行一个，点击「保存设置」。
2. 进入「自动化 → 消息与事件」。
3. 按需调整「QQ群 → 游戏」「游戏 → QQ群」与「进退服通知」。
4. 点击「保存设置」或底部「保存全部设置」，保存后立即生效。
5. 分别发送一条群文字、一条游戏聊天，再让测试玩家进服或离服，核对打开的方向是否送达。

这些同步开关是主程序全局设置，影响所有已配置服务器。每台服发送到哪些群由自己的关联群列表决定。

| 面板设置 | 配置字段 | 示例配置默认值 | 作用 |
| --- | --- | --- | --- |
| QQ群 → 游戏 | `features.qq_to_mc` | 开启 | 将关联群的普通消息广播到对应游戏服 |
| 游戏 → QQ群 | `features.mc_to_qq` | 开启 | 将游戏聊天发送到该服所有关联群 |
| 进退服通知 | `features.join_quit` | 开启 | 将玩家加入、离开游戏的事件发送到关联群 |

业务设置无需重启主程序；如果改了游戏端的连接地址、服务器 ID 或令牌，则按[快速开始](quick-start.md)同步游戏端配置并重启游戏服。

### 关键词回复与定时公告

关键词回复属于内置插件：进入「扩展 → 插件管理」，找到「关键词回复」，点击「管理回复」，保存插件设置并确认插件已启用。回复按整条消息精确匹配，例如设置 `规则` 后，群里发送 `规则` 才会触发。

定时公告属于内置「定时任务」插件，在插件卡片点击「管理任务」配置。它与聊天同步开关分别管理，详情见[定时任务](automation-and-whitelist.md)。插件权限也会影响插件自己的回复、通知与公告。

## 游戏与 QQ 示例

在关联群发送普通文字：

```text
大家好，今晚一起建造吗？
```

已绑定为 Steve 的发言会在游戏中显示为：

```text
[QQ] Steve: 大家好，今晚一起建造吗？
```

玩家 Steve 在游戏聊天中发送 `大家好`，群内显示类似：

```text
[生存服] Steve: 大家好
```

也可在群中先检查连接：

```text
状态
在线
```

`帮助`、`状态`、`绑定` 等内置命令以及已经由插件处理的消息会走对应功能，不再作为普通聊天发送到游戏。注册、QQ 登录确认和密码请按各自流程操作；游戏密码只在登录命令中输入，QQ 登录确认只能私聊机器人。

## 预期结果

群文字只送到该群对应的游戏服；游戏聊天与进退服通知送到该服所有关联群。群与群之间没有直接转发聊天的功能。

进退服通知示例：`[生存服] Steve 加入了游戏`。在「活动 → 运行日志」选择「消息同步」，可以看到对应方向的记录。

消息以实际连接与发送结果为准。游戏到群发送失败会记录错误，不在重连后重放；Bukkit 游戏端也会丢弃超过 30 秒的旧聊天事件，避免长时间断线后集中补发。

## 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 两个方向都没有消息 | 先检查 QQ、游戏桥接和群号关联，再确认设置已保存；使用[连接诊断](diagnostics-and-templates.md)定位 |
| 只有一个方向有消息 | 分别检查两个方向的开关、QQ 发送权限及游戏端事件；在运行日志筛选「消息同步」「错误记录」 |
| 状态能回复，普通群消息不进游戏 | 检查「QQ群 → 游戏」和游戏桥接；确认测试文字没有触发内置命令或关键词回复 |
| 游戏聊天没有发到群 | 检查「游戏 → QQ群」；确认玩家已登录、聊天未被其他插件取消，检查机器人发群消息是否失败 |
| 图片没显示或只有占位文字 | 当前不转发图片本体；消息段中的图片可转为占位文字，旧式 CQ 字符串中的非文本段会移除 |
| 进退服通知重复 | 检查是否同时启用了 JSON 插件的自定义通知与核心「进退服通知」，按需求保留相应配置 |
| 很长的消息被截断、格式颜色消失 | 基础聊天会移除控制字符与游戏颜色代码，正文最多保留 500 字符 |
| 高频消息没有全部送达 | 群消息有频率限制，队列也有容量和有效期；放慢测试频率并检查错误日志 |
| 重连后没有补发断线期间消息 | 这是当前的过期与失败处理；恢复连接后发送新消息检查 |
