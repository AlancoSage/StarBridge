# 管理面板使用指南

本页说明在哪设置功能、怎样保存，以及怎样判断操作成功。当前对应 Bot 0.6.21；第一次部署先阅读 [快速开始](quick-start.md)。

「接入空间 → 机器人连接 → 接入设置」可选择 OneBot 11 或 QQ 官方机器人。官机填写 AppID / AppSecret，管理员与群关联使用接入信息中的完整身份，步骤及能力限制见 [官机接入](qq-official.md)。

“有尚未保存的更改”按当前主配置与最近一次载入或保存的内容比较。修改后改回原值、临时新增再移除服务器或指令，会自动清除提醒；搜索、筛选、查看密钥、插件本地预览和下载连接配置中的临时地址不改变主配置。仍有其他字段变更、指令未填完整或名称重复时，提醒会保留。

「自动化 → 消息与事件」还可启用[指定指令图片回复](image-replies.md)：按名单选择需要转图的指令，保存全部设置后生效。「在线」「状态」采用浅色霜白毛玻璃面板、柔和蓝粉插画背景、深灰文字和少量珊瑚色点缀，分区展示人数、连接状态、更新时间与玩家名单。内容来自关联服务器的真实数据，离线时不显示旧玩家；玩家配有本地生成的名字首字头像，其他指令使用同风格毛玻璃文字简报。内置原创插画无需联网，也无需新增配置。此样式仅用于回复图片，不改变管理面板界面。

展开「排版预览」后，默认使用示例文字，也可选择已保存的服务器；仅「在线」「状态」使用所选服务器的真实状态与玩家名单，其他指令仍使用预览文字。选择和生成预览不发送 QQ，也不改变保存状态。

## 登录面板

1. 在 Bot 所在机器打开默认地址 `http://127.0.0.1:5800/`；地址或端口修改过时使用实际值。
2. 服主和团队成员都填写自己的用户名、密码，点击「登录」。已有团队账号可继续使用。
3. 首次尚未创建服主账号时，点击独立的「创建服主账号」，填写服主用户名、密码与确认密码，并使用本机 `config.toml` 的 `app.admin_token` 完成首次授权。创建成功后，使用新用户名和密码登录。

服主用户名为 3–32 位字母、数字、下划线或短横线，密码为 10–128 位。已创建服主账号后，首次设置入口不再显示。

`app.admin_token` 保留用于首次授权和兼容管理 API，不是日常登录密码；OneBot 与游戏服务器连接令牌也不能用来登录面板。团队权限决定可访问的页面和接口，创建方法见 [团队管理员](team-and-operations.md#多管理员)。

## 从哪个入口开始

桌面端从左侧分组导航进入各个页面；需要更多操作空间时可以收起侧栏。窄屏设备通过顶部菜单按钮展开导航，选择页面后收起菜单。当前页面名称显示在工作区顶部。

| 侧栏分组 | 页面入口 | 用途与教程 |
| --- | --- | --- |
| 总览 | 运行概览 | 查看 QQ、服务器和关联群的当前状态 |
| 接入空间 | 机器人连接、服务器列表、网站绑定、连接诊断 | 连接三个组件；见 [OneBot](onebot-connection.md)、[官网](website-deployment.md)、[诊断](diagnostics-and-templates.md) |
| 自动化 | 消息与事件、游戏指令 | 配置文本联动、进退服通知与预设命令；见 [消息同步](message-sync.md)、[群命令](group-commands.md) |
| 成员 | 玩家管理、账号绑定、注册账号、游戏登录 | 管理档案、查询绑定、设置邮件注册和认证；见 [玩家管理](player-management.md)、[QQ 绑定](account-binding.md)、[游戏登录](game-login.md) |
| 扩展 | 插件管理、定时任务 | 启用关键词回复、导入 JSON 插件、管理任务；见 [插件指南](plugin-development.md)、[任务与申请](automation-and-whitelist.md) |
| 活动 | 运行日志、故障提醒、服务器统计 | 查看真实连接和执行记录；见 [运行维护](team-and-operations.md) |
| 设置 | 软件设置、功能开关、备份与恢复、管理员与权限、更新与回退、部署模板 | 管理运行环境、可选功能和维护操作；见 [备份](backups.md)、[更新](updates.md) |

「游戏指令」打开后的页面标题是「远程命令」。白名单申请、工单与申诉、跨服处罚需要在「设置 → 功能开关」开启后才显示对应成员页面。团队成员只会看到权限允许访问的入口。

顶部的主题按钮切换明暗外观，主题选择保存在当前浏览器中。切换主题和收起导航不会更改 Bot 配置。

点击顶部「查找功能」，或按 `Ctrl + K`，可以按名称查找并直接进入功能页面。查找结果遵循当前账号权限，跳转时会保留配置草稿。

## 保存一次设置

1. 打开需要修改的页面，先确认当前配置已经载入。
2. 修改配置字段后，使用顶部或底部的「保存全部设置」。带独立表单的功能使用该表单的保存按钮。
3. 等待成功提示，再检查「总览 → 运行概览」或「活动 → 运行日志」中的实际状态。

切换页面或关闭接入设置弹窗会保留当前页面会话中的配置草稿。全局保存会同时应用其他页面尚未保存的配置；未保存时请先核对底部的草稿提示。重新载入配置会丢弃草稿，页面会先请求确认。发生版本冲突时重新载入当前配置，核对差异后再保存；不要连续点击覆盖其他管理员的编辑。

通常业务设置保存后立即应用。监听地址、端口和数据库路径需要重启；数据库路径改变不会自动迁移旧数据。OneBot 或游戏令牌改变后，需要同时更新对应实现端或游戏插件的配置。

「接入空间 → 机器人连接」通过机器人卡片展示连接状态、QQ、关联群和管理员数量。点击「接入设置」在弹窗内修改账号与连接参数。返回或关闭弹窗会保留草稿；弹窗中的「保存全部设置」也会保存其他页面尚未保存的配置。

## 配置多台服务器

在「接入空间 → 服务器列表」为每台游戏服设置唯一 ID、名称和独立令牌。一个群关联一台服务器，一台服务器可以关联多个群。群内状态、绑定和预设命令按这份路由选择目标。

允许不配置服务器。删除服务器或改变 ID 不会把旧绑定自动迁移到新 ID；删除前先核对关联群、账号关系和待执行任务。

## 怎样确认操作完成

运行概览中的 QQ 连接、服务器在线情况和执行记录均来自实际运行状态。配置了连接参数或保存成功，还需要等待对应组件连入才能显示在线；没有配置服务器时可以直接前往服务器列表添加。

| 页面状态 | 含义 | 下一步 |
| --- | --- | --- |
| 设置保存成功 | Bot 已接收设置 | 涉及外部组件时继续检查连接 |
| QQ 已连接 | OneBot WebSocket 正常 | 在关联群执行 `状态` 验收 |
| 服务器在线 | 近期收到游戏桥接心跳 | 测试群查询、聊天和游戏端回执 |
| 操作已提交 / 等待确认 | Bot 已创建任务 | 等待游戏服回传结果，再查看成功或失败 |
| 服务器失联 | 暂未收到有效心跳 | 到「连接诊断」检查，不直接认定游戏进程已关闭 |

面板适配桌面和窄屏，表格在自身区域滚动。切页时首屏标题或小卡片短暂淡入，手机菜单滑入，弹窗和按钮提供轻微反馈；动画播放后停止，不会随状态刷新反复播放。后台标签页暂停状态刷新，短时界面动画遵循系统的减少动态效果设置。遇到显示或连接问题见 [常见问题](troubleshooting.md)。
