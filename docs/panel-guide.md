# 管理面板使用指南

本页说明在哪设置功能、怎样保存，以及怎样判断操作成功。当前对应 Bot 0.6.9；第一次部署先阅读 [快速开始](quick-start.md)。

## 登录面板

1. 在 Bot 所在机器打开默认地址 `http://127.0.0.1:8088/`；地址或端口修改过时使用实际值。
2. 服主选择「服主管理令牌」，填写自己 `config.toml` 中的 `app.admin_token`。
3. 团队成员选择「管理员账号」，使用服主创建的用户名和密码。

管理令牌不是 QQ 连接令牌或游戏服务器令牌。团队权限决定可访问的页面和接口，创建方法见 [团队管理员](team-and-operations.md#多管理员)。

## 从哪个入口开始

| 顶部入口 | 页面按钮 | 用途与教程 |
| --- | --- | --- |
| 主页 | 运行概览 | 查看 QQ、服务器和关联群的当前状态 |
| 接入空间 | 机器人连接、服务器列表、网站绑定、连接诊断 | 连接三个组件；见 [OneBot](onebot-connection.md)、[官网](website-deployment.md)、[诊断](diagnostics-and-templates.md) |
| 自动化 | 消息与事件、游戏指令 | 配置文本联动、进退服通知与预设命令；见 [消息同步](message-sync.md)、[群命令](group-commands.md) |
| 成员 | 玩家管理、账号绑定、注册账号、游戏登录 | 管理档案、查询绑定、设置邮件注册和认证；见 [玩家管理](player-management.md)、[QQ 绑定](account-binding.md)、[游戏登录](game-login.md) |
| 扩展 | 插件管理、定时任务 | 启用关键词回复、导入 JSON 插件、管理任务；见 [插件指南](plugin-development.md)、[任务与申请](automation-and-whitelist.md) |
| 活动 | 运行日志、故障提醒、服务器统计 | 查看真实连接和执行记录；见 [运行维护](team-and-operations.md) |
| 设置 | 软件设置、功能开关、备份与恢复、管理员与权限、更新与回退、部署模板 | 管理运行环境、可选功能和维护操作；见 [备份](backups.md)、[更新](updates.md) |

「游戏指令」打开后的页面标题是「远程命令」；顶部「设置」内的页面面包屑使用「系统」。白名单申请、工单与申诉、跨服处罚需要在「设置 → 功能开关」开启后才显示对应成员页面。

## 保存一次设置

1. 打开需要修改的页面，先确认当前配置已经载入。
2. 修改字段；有「保存设置」的页面点击保存，带独立表单的功能使用该表单的保存按钮。
3. 等待成功提示，再检查「主页」或「活动 → 运行日志」中的实际状态。

网页存在未保存修改时会保留草稿。发生版本冲突时重新载入当前配置，核对差异后再保存；不要连续点击覆盖其他管理员的编辑。

通常业务设置保存后立即应用。监听地址、端口和数据库路径需要重启；数据库路径改变不会自动迁移旧数据。OneBot 或游戏令牌改变后，需要同时更新对应实现端或游戏插件的配置。

## 配置多台服务器

在「接入空间 → 服务器列表」为每台游戏服设置唯一 ID、名称和独立令牌。一个群关联一台服务器，一台服务器可以关联多个群。群内状态、绑定和预设命令按这份路由选择目标。

允许不配置服务器。删除服务器或改变 ID 不会把旧绑定自动迁移到新 ID；删除前先核对关联群、账号关系和待执行任务。

## 怎样确认操作完成

| 页面状态 | 含义 | 下一步 |
| --- | --- | --- |
| 设置保存成功 | Bot 已接收设置 | 涉及外部组件时继续检查连接 |
| QQ 已连接 | OneBot WebSocket 正常 | 在关联群执行 `状态` 验收 |
| 服务器在线 | 近期收到游戏桥接心跳 | 测试群查询、聊天和游戏端回执 |
| 操作已提交 / 等待确认 | Bot 已创建任务 | 等待游戏服回传结果，再查看成功或失败 |
| 服务器失联 | 暂未收到有效心跳 | 到「连接诊断」检查，不直接认定游戏进程已关闭 |

面板适配桌面和窄屏，表格在自身区域滚动。后台标签页暂停状态刷新，动画遵循系统的减少动态效果设置。遇到显示或连接问题见 [常见问题](troubleshooting.md)。
