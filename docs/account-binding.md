# 账号绑定

适用于 Myrinbot Bot **0.6.22** 与 Paper / Spigot / Folia 游戏插件 **0.5.3**。模组服请先安装[对应加载器的游戏端](mod-game-ends.md)。

## 用途

把自己的 QQ 与某台服务器中的游戏 UUID 关联，方便查询身份、在聊天同步中使用玩家名，以及启用游戏登录后通过绑定 QQ 确认本次登录。

绑定、社区账号注册、游戏登录是三个流程：`/qbind` 生成绑定码；`/申请`、`/注册` 验证邮箱并创建社区账号；`/login`、`/qqlogin` 验证本次游戏连接。绑定不会自动注册账号、加入白名单或授予游戏权限。

## 使用前提

- QQ 机器人已连接，目标群已在「接入空间 → 服务器列表」关联到这台游戏服。
- 游戏端已连接 Myrinbot 主程序，玩家能进入这台服务器。
- 如果启用了游戏登录，先完成登录，再使用 `/qbind`。尚未绑定的玩家不能用 QQ 登录建立第一次绑定，可按服主配置先通过密码及原登录插件验证。
- 管理员手动绑定前，需要核实 QQ 使用者与游戏 UUID 确实属于同一人。

每台服务器内，一个 QQ 对应一个游戏 UUID，一个 UUID 只能绑定一个 QQ。不同服务器分别管理绑定；相同 QQ 可在不同服务器绑定不同 UUID。

## 面板操作步骤

### 查看绑定

1. 登录管理面板，进入「成员 → 账号绑定」。
2. 输入玩家名、QQ 号或服务器名称，或用「全部服务器」下拉框筛选。
3. 核对游戏玩家、QQ 账号、所属服务器与绑定时间。这个页面用于查询。

### 管理员添加或解除绑定

1. 进入「成员 → 玩家管理」，搜索玩家并点击「详情」。
2. 在「绑定账号」中选择「服务器」，填写「QQ 号」，核实身份后点击「添加绑定」。已有绑定冲突时，先处理原记录。
3. 解除某台服务器的绑定，在详情的对应记录旁点击「解绑」。列表中的「解绑」以及「批量解绑」会解除所选玩家在**全部服务器**的绑定，提交前核对确认提示。

手动新增档案需要真实 UUID，步骤见[玩家管理](player-management.md)。不要仅根据同名玩家推断账号身份。

### 可选的绑定事件

1. 进入「自动化 → 消息与事件」，也可从绑定页点击「设置退群解绑与群名片 →」。
2. 按需开启「退群自动解绑」或「绑定后更新群名片」。
3. 点击「保存设置」或底部「保存全部设置」。这些业务开关保存后立即生效。

| 设置 / 参数 | 默认或限制 | 说明 |
| --- | --- | --- |
| 绑定验证码 | 8 位十六进制字符，5 分钟有效 | 使用一次后失效；再次获取会使同服同 UUID 的旧码失效 |
| `/qbind` 间隔 | Bukkit 插件至少 20 秒 | 主程序另限制同服同 UUID 每分钟最多获取 3 次 |
| 群内验证码尝试 | 同群同 QQ 每分钟最多 5 次 | 过多时提示稍后重试 |
| 退群自动解绑 `unbind_on_leave` | 默认关闭 | 退出该服任意一个关联群，就解除该服务器的绑定 |
| 绑定后更新群名片 `set_group_card` | 默认关闭 | 群内验证码绑定成功后，尝试把该群名片改为玩家名；机器人需要相应管理权限 |

移除服务器会保留旧绑定；更改服务器 ID 会使用新的绑定范围，不会迁移原记录。

## 游戏与 QQ 命令示例

游戏内输入：

```text
/qbind
```

游戏会提示向服务器 QQ 群发送绑定码。下面的 `A1B2C3D4` 仅演示格式，请替换为自己本次收到的验证码：

```text
绑定 A1B2C3D4
我的绑定
```

需要解除自己的绑定时，在这台服务器的关联群发送：

```text
解绑
```

上述群命令不需要加斜杠或 @ 机器人。只在关联群生效，绑定码必须属于该群对应的服务器。不要转发自己的绑定码。

## 预期结果

成功时，群内回复类似「绑定成功：Steve（生存服）」，`我的绑定` 返回该服关联的玩家名，面板出现一条绑定记录。记录保存于本地 SQLite，重启主程序后仍保留。

开启 QQ 到游戏的同步后，这个 QQ 的普通聊天使用绑定玩家名显示。启用 QQ 游戏登录后，`/qqlogin` 仍需本次私聊确认；已经绑定不表示自动登录。

开启更新群名片后，若改名片失败，回复会追加权限提示；已经成功建立的绑定仍然有效。解绑后应再次用 `我的绑定` 核对。

## 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 游戏提示先完成登录 | 先完成这次游戏登录，再获取绑定码；登录方式见[游戏登录](game-login.md) |
| `/qbind` 不存在或无权限 | 检查游戏端是否安装并正常加载；Bukkit 权限为 `starbridge.bind`，默认允许玩家使用，另有权限插件时检查是否被覆盖 |
| 获取验证码失败 | 在总览检查游戏桥接，核对游戏端的主程序地址、`server-id` 和令牌；排查入口见[连接诊断](diagnostics-and-templates.md) |
| 验证码无效或已过期 | 确认发送到了正确服务器的群；检查是否超过 5 分钟、已使用或已获取新码 |
| QQ 或游戏账号已有绑定 | 用 `我的绑定` 或面板查看现有记录，由本人或管理员核实后解绑再绑定 |
| 群内完全没有回复 | 确认 QQ 已连接、群号已关联、消息非匿名；降低发送频率后重试 |
| 退出其中一个群后绑定消失 | 检查「退群自动解绑」；同服多个关联群中退出任意一个都会触发 |
| 群名片没有更新 | 确认开关、机器人群管理权限；管理员手动添加绑定不会触发群内改名片流程 |

核对日志时进入「活动 → 运行日志」，选择「账号绑定」。分享排查材料时遮盖 QQ 号、绑定码、邮箱与各类令牌。
