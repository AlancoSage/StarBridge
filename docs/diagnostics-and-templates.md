# 连接诊断与部署模板

适用版本：Bot 0.6.24。先用本页核对连接和配置，再按 [常见问题](troubleshooting.md) 排查具体症状。设置在面板内调整；诊断无需显卡，也不会持续连接外部检测服务。

## 检查连接

进入 **接入空间 → 连接诊断**，先查看被动检查结果。

| 检查项 | 如何判断 | 后续操作 |
| --- | --- | --- |
| Python | 显示实际版本与系统 | 需要 Python 3.11+ |
| QQ | 使用真实 OneBot WebSocket 状态 | 检查反向 WS 地址、账号和令牌 |
| 游戏服 | 使用近期心跳及插件能力 | 检查服务器 ID、地址和令牌；缺少处罚能力时更新 JAR |
| 邮件 | 区分未配置和待检测 | 点击「检测 SMTP」，检查连接、TLS 与认证，不发送邮件 |
| 官网 | 显示接入状态 | 点击「检测官网 API」，只读取公开社区信息，不携带密钥 |
| 磁盘 | 显示实际可用空间 | 为数据备份和更新运行环境预留空间 |

游戏端会报告核心名称、版本与 Java 版本。旧插件未上报时显示「未上报」，不会推测版本。API 地址为相对路径时，使用网站绑定页面的浏览器检测；服务端检测需要完整 HTTP(S) 地址。

诊断权限为 `diagnostics.run`；邮件检测只使用已经保存的 SMTP 设置。检测不会验证真实收件是否成功，实际邮件投递仍需通过注册流程联调。

## 选择部署模板

进入 **设置 → 部署模板**，选择模板，点击「预览模板」。

| 模板 | 配置效果 |
| --- | --- |
| 单服联动 | 没有服务器时创建生存服，启用双向文本同步和进退服通知 |
| 多服社区 | 保留现有服务器，少于两台时补充创造服 |
| 仅 QQ 确认登录 | 对配置中的服务器启用游戏认证，关闭密码登录、开启 QQ 登录 |
| 聊天联动 | 关闭游戏认证，保留聊天同步 |

模板不会替你登录 QQ、安装游戏插件或填写真实群号。仅 QQ 登录需要玩家先绑定 QQ。模板保留已有服务器；需要删服时，请在服务器列表操作。

## 导出与导入配置

1. 点击「导出无令牌配置」，得到 JSON 文件。
2. 在目标实例选择该 JSON，或导入主配置 TOML，最大 200 KiB。
3. 检查预览中的新增、移除服务器、关联群、消息开关和登录策略。
4. 点击「应用此配置」。预览有效期五分钟，期间配置或登录策略变化时需要重新预览。

导出不包含管理、OneBot、游戏令牌和业务数据库。导入保留本机面板监听设置、数据库路径、管理令牌、OneBot 令牌与同 ID 的游戏令牌；新服务器生成随机令牌。关键词插件与业务数据继续使用本机内容。SMTP、网站绑定和插件设置使用各自的管理页面，不属于此主配置导入。

移除服务器会撤销该服的待执行操作和验证码。此功能只允许服主使用。导出的 JSON 可以带游戏认证策略；导入普通 TOML 不修改认证策略。
