# 群命令

适用于 Myrinbot Bot **0.6.19** 与 Paper / Spigot / Folia 游戏插件 **0.5.3**。以下基础命令来自主程序；预设命令、插件命令及可选功能以当前服务器配置为准。

QQ 官机模式需在群内先 @机器人。`接入信息` 可在尚未关联服务器的群获取群与用户身份；管理员填写返回的 `qug:` 身份。官机邮箱注册、群管理及通知发送范围见 [官机接入](qq-official.md)。

## 用途

在关联 QQ 群查询游戏状态、绑定或解绑账号，并让指定机器人管理员执行预先配置好的控制台命令。开放注册或白名单申请后，成员也可通过群命令提交相应请求。

## 使用前提

- QQ 已连接，机器人能收发群消息，这个群已在「接入空间 → 服务器列表」关联。
- 普通基础命令供群成员使用；`执行` 只允许「机器人连接」配置的管理员 QQ。
- 远程执行要求游戏桥接在线，并已保存该服的固定控制台命令。
- 注册、白名单申请和插件命令需要对应功能已开放且权限允许。

群主、QQ 群管理员、面板团队管理员与机器人命令管理员是不同的身份。远程执行核对的是 `onebot.admins` 中的 QQ，拥有其他身份不自动获得这项权限。

## 面板操作步骤

### 配置命令管理员

1. 用服主账号的用户名和密码登录面板，进入「接入空间 → 机器人连接」。
2. 在「管理员 QQ 号」填写允许远程执行的 QQ 号。
3. 点击「保存设置」或底部「保存全部设置」。

### 配置服务器预设命令

1. 进入「自动化 → 游戏指令」。进入后的页面标题为「远程命令」。
2. 若尚未添加服务器，点击空页面的「前往添加服务器」，到「接入空间 → 服务器列表」点击「＋ 添加服务器」，填写并保存服务器设置，再返回远程命令页。
3. 点击页面顶部始终可见的「＋ 新建指令」。只有一台服务器时直接生成空白草稿；有多台服务器时，在「新建指令」窗口选择「目标服务器」，再点击「创建指令草稿」。服务器卡片内的「＋ 添加命令」也可为该服新增草稿。
4. 分别填写「群内命令名」与「控制台命令」。例如群内命令名 `在线检查`，控制台命令 `list`。卡片会展示「群内用法 → 目标服务器 → 固定执行内容」，检查目标和内容后可点击「复制群内用法」，然后点击「保存全部设置」。
5. 等游戏端下一次心跳同步白名单后，在该服的关联群测试。

尚无命令时，页面会显示新建指令的操作提示。新增或移除命令先修改页面草稿；需要删除时，点击命令卡片的「×」移除按钮，并点击「保存全部设置」使修改生效。

控制台命令填写完整固定内容，通常不加开头 `/`。群消息只选择命令名，不会拼接额外参数。每台服务器可以有不同的名单；新人接手时先查看面板，确认名称与内容。

| 设置 / 参数 | 示例或限制 | 说明 |
| --- | --- | --- |
| 管理员 QQ `onebot.admins` | QQ 号列表 | 只有名单内发送者能使用 `执行` |
| 群内命令名 | `在线检查` | 群中发送 `执行 在线检查`，名称须匹配该服的配置 |
| 控制台命令 | `list` | 实际下发固定内容；每台服最多 100 项预设命令 |
| 示例配置第二项 | `性能检查` → `tps` | 来自 `config.example.toml`；`tps` 是否存在取决于服务端 |
| 游戏端白名单 | `allowed-commands` | 从 0.5.2 起，插件从主程序心跳自动同步，并再次检查完整命令 |
| 关联群 `servers.groups` | 每群一台服 | 查询与执行路由到这个群对应的服务器 |

关键词回复和自定义群命令在「扩展 → 插件管理」管理；定时执行使用内置「定时任务」插件。两者不是额外的群管理指令，说明见[插件开发](plugin-development.md)与[定时任务](automation-and-whitelist.md)。

## 游戏与 QQ 命令示例

### 基础命令

基础中文命令不需要斜杠或 @。命令与参数之间使用一个普通空格。

| QQ 群消息 | 用途与返回 |
| --- | --- |
| `帮助`、`help` 或 `/help` | 查看内置帮助；已开放的注册、白名单申请会追加说明 |
| `状态` | 返回当前服桥接状态、在线人数与游戏版本 |
| `在线` | 同上，并列出在线玩家；无人在线时显示暂无玩家 |
| `绑定 A1B2C3D4` | 消费游戏绑定码；示例码需换为本次收到的真实码 |
| `我的绑定` | 查询本人在这台服务器的绑定 |
| `解绑` | 解除本人在这台服务器的绑定 |
| `执行 在线检查` | 指定管理员执行该服配置的 `在线检查` |

绑定码需先在对应游戏服内获取：

```text
/qbind
```

启用游戏登录后先完成登录。完整过程见[账号绑定](account-binding.md)。

### 可选命令

| QQ 群消息 | 开放条件 |
| --- | --- |
| `/申请 Steve <你的QQ号>` | 社区注册已开启；把占位符替换为发消息的本人 QQ，邮件发到该 QQ 邮箱 |
| `/注册 <邮件验证码>` | 原申请人，在原申请群确认；创建社区账号，不等于游戏绑定 |
| `/白名单 Steve 首次入服` | 已开放群内白名单申请，且符合服主设置的资格要求 |
| `/白名单状态` | 查询本人在当前服务器的最近白名单申请 |
| `规则` 等关键词 | 内置「关键词回复」插件已启用，并配置了精确匹配的回复与权限 |
| 导入插件声明的群命令 | 对应 JSON 插件已启用，且服务器、群和使用者权限允许 |

群注册的反馈可能展示申请邮箱。如不希望邮箱出现在群里，使用服主提供的[注册网页](account-api.md#注册网页与网站接入)。示例中所有占位符均需替换，不要照抄尖括号。

`/确认登录 <确认串>` 与 `/拒绝登录 <确认串>` 只能**私聊机器人**，不能在群里确认本次游戏登录；登录密码不发送到群中，详见[游戏登录](game-login.md)。

## 预期结果

基础命令只处理该群对应的服务器。「状态」表示最近游戏端心跳是否正常，不是直接探测 Minecraft 地址；超过 15 秒没有心跳会显示桥接离线。

远程执行先回复「已提交『在线检查』，等待服务器执行。」之类的文字，游戏插件执行后再返回结果。只有收到执行结果才能判断成功；部分命令没有文本输出，部分插件的异步日志不保证回传。

预设执行只发送已保存的完整命令。比如只配置了 `在线检查` 时，`执行 在线检查 Steve` 不会替 `list` 添加玩家参数；未匹配到配置名称会回复可用命令列表。要改变固定内容，由服主在面板修改并保存。

## 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 群内所有命令都不回复 | 检查 QQ 连接、群号路由、机器人发送权限；匿名消息、机器人自己的消息不会处理 |
| 只有 `执行` 提示权限不足 | 核对发送消息的 QQ 是否在「管理员 QQ 号」中，并确认已保存 |
| 回复可用命令列表 | 对照当前服的命令名；不要把 `list` 当成群内名，除非面板就是这样配置的 |
| 回复桥接离线，命令未提交 | 检查游戏端地址、服务器 ID、令牌与运行日志，恢复连接后再执行 |
| 插件拒绝执行，命令不在白名单 | 检查游戏端是否为新版、心跳是否正常；旧版需升级，或按对应版本手动同步白名单 |
| 返回服务器未找到命令 | 检查服务端或目标插件是否提供该控制台命令，例如部分核心没有 `tps` |
| 先提示提交，却没有后续结果 | 检查游戏端与「活动 → 运行日志」的「命令执行」「错误记录」；先核对实际执行情况再重试 |
| 关键词或插件命令无响应 | 检查插件启用状态、精确匹配及「权限」中的群、服务器、使用者范围 |
| 注册或白名单申请被拒绝 | 根据文字提示检查功能是否开放、本人 QQ、邮件额度或申请资格；参阅对应功能页 |
| 高频发送偶尔不回复 | 群消息限流为同群同 QQ 每 10 秒最多 12 条；绑定尝试还有独立限制，稍等后重试 |

排查需要展示命令内容时，先遮盖其中可能包含的敏感参数；不要公开 QQ 号、邮箱、验证码、密码或令牌。
