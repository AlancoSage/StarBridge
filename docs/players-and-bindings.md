# 玩家档案与 QQ 绑定

玩家档案、QQ 绑定和社区注册是三种不同的记录。可以先配置文本聊天，再按社区需要启用这些账号功能。

| 要做的事 | 应使用的功能 | 教程 |
| --- | --- | --- |
| 查看游戏身份、在线记录、IP 和手动归属地 | 玩家管理，按真实 UUID 汇总档案 | [玩家管理](player-management.md) |
| 让游戏玩家验证并绑定本人 QQ | 游戏 `/qbind`，群内 `绑定 验证码` | [QQ 绑定](account-binding.md) |
| 通过邮箱注册社区账号并设置网站密码 | 网页或群注册、邮件验证码 | [注册与密码](account-api.md) |
| 使用注册密码或绑定 QQ 登录游戏 | 开启指定服的游戏认证，按对应引擎验证 | [游戏登录](game-login.md) |
| 查询当前关联服或执行预设群命令 | QQ 群命令与管理员范围 | [群命令](group-commands.md) |

在「成员 → 账号绑定」查询已有关系；管理员为玩家绑定或解绑，在「成员 → 玩家管理」的玩家详情操作。未登录的玩家不能靠 `/qbind` 绕过游戏认证，QQ 单独登录模式需要先有已核实的绑定。

注册同名账号不会自动获得别人的 Minecraft UUID 或原登录插件账户。更改 UUID、重新关联或管理员代绑定时，需要先核对真实身份。

其他相关功能：[消息同步](message-sync.md)、[白名单申请](automation-and-whitelist.md#白名单申请)、[工单与跨服处罚](community-operations.md)。
