# StarBridge 0.6.4

- 新增 Fabric 1.16.5、1.18.2、1.19.2、1.20.1 和 1.21.1 服务端模组，保留现有 Paper / Spigot、Forge 与 NeoForge 游戏端。
- 五个 Fabric 版本均支持 QQ 聊天联动、玩家档案、管理操作、白名单申请、绑定码及注册密码 / QQ 确认登录，包含 `/l`、`/ql` 和 `/logout`。
- Fabric 1.16.5 使用 Java 8，1.18.2–1.20.1 使用 Java 17，1.21.1 使用 Java 21；固定验证 Fabric Loader 0.16.14，每个 Minecraft 版本提供独立 JAR，星桥无需 Fabric API 或客户端模组。
- 登录保护覆盖移动、普通命令、聊天、背包与交互、伤害和拾取；保留新版原生聊天确认与签名解析，密码不进入原生命令日志；丢弃旧版自定义数据包时释放其独立缓冲区。
- 管理面板增加 Fabric 版本选择、对应模组及 UTF-8 properties 配置下载、专用安装指南，并保持小屏幕适配。
- 发布流程自动构建并校验十二个模组游戏端，包含强制保护 Mixin、版本、Java 字节码和校验文件；完整部署包携带全部游戏端。
- 增加 Fabric 多版本安装、升级、开发构建与排查文档。验证范围为指定加载器的真实专用测试服及离线协议客户端，QQ 私聊使用隔离模拟；整合包组合、正版签名与真实 QQ 环境仍需部署联调。
