# StarBridge 0.6.1

- GitHub 私有 Release 更新源，可在面板配置仓库和读取令牌。
- 展示正式版本列表，下载完整部署包并校验 SHA256 和文件大小。
- GitHub 附件跳转时移除令牌，令牌不会返回浏览器或写入发布包。
- 版本发布脚本提供 Bot、官网、Minecraft 插件与 SHA256 校验文件，已发布版本不会被覆盖。
- GitHub 自动发布工作流：Bot 版本号变更后测试、构建并发布对应版本。

保留 ZIP 上传、自定义 HTTPS 更新源、升级前备份和失败回退。私有仓库更新需要有仓库读取权限的 GitHub 令牌，普通用户不会自动获得仓库访问权。Minecraft 插件版本仍为 0.5.0。
