# Myrinbot v0.6.21

指定指令的图片回复改为浅色霜白毛玻璃风格：柔和蓝粉背景保留 Myrinbot 原创冬日插画，搭配细白边、小圆角、深灰文字和少量珊瑚色点缀。人数、连接状态、更新时间与玩家名单分区展示，其他已选指令使用同风格文字简报。此次调整仅影响回复图片，管理面板界面保持原样；现有开关和指令名单继续生效，无需新增配置。

- 「在线」「状态」继续只使用当前群关联服务器的真实数据，离线时隐藏过期玩家；面板预览可选择已保存服务器，默认仍使用示例文字。
- 毛玻璃面板通过背景模糊与透光叠层呈现。插画、中文字体与名字首字头像均在本地处理，不依赖第三方头像服务。
- 支持长名单分页，每次最多四页，每页 PNG 不超过 2 MiB；超出边界仍按现有规则回退文字。预览不会保存配置、发送 QQ 或触发未保存提示。

验证范围包括中文渲染与分页、离线数据、群隔离与预览权限、草稿状态、OneBot 消息段和 QQ 官机模拟图片上传。未使用真实 QQ 账号或腾讯应用实测投递，部署后仍需按应用权限验收。

完整部署包为 `Myrinbot-Windows-0.6.21.zip`，独立官网包为 `Myrinbot-website.zip`。保留内容相同的 `StarBridge-*` 兼容附件及 `SHA256SUMS.txt`，供现有升级器使用。Bukkit 插件仍为 0.5.3，Forge / NeoForge / Fabric 模组仍为 0.1.1。
