# VexBot v0.6.32

内置管理控制台改用思源黑体，中文、英文和数字采用统一的本地字体。

- 使用 Adobe 官方简体中文思源黑体可变字体，正文、侧栏、按钮、输入框和标题按各自字重显示。
- 字体随部署包提供，通过 Bot 同源加载并缓存；加载过程中或加载失败时保留系统字体，页面仍可操作。
- 保留完整 SIL Open Font License 1.1 许可、版权和来源校验记录，字体资源兼容现有升级器。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.32.zip`、内容相同的 `StarBridge-Windows-0.6.32.zip`、配套游戏端和官网附件及 `SHA256SUMS.txt`，保留现有升级协议。
