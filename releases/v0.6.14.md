# Myrinbot 0.6.14

微调指令、文字回复与规则扩展的配置流程，明确每种功能的操作边界。

- 远程指令卡片展示「群内用法 → 目标服务器 → 固定执行内容」，支持复制群内用法；服务器改名和草稿修改会同步更新预览。
- 关键词回复使用独立问答编辑器。新增本地草稿匹配检查，展示匹配、未匹配和无效草稿结果；检查不发送群消息或执行服务器命令，不影响未保存状态。
- 扩展页面明确 Myrinbot JSON 声明式规则格式，保留作者和版本信息；新增交互设计文档。

既有群内 `执行 命令名`、配置与插件文件继续兼容。Windows 部署包为 `Myrinbot-Windows-0.6.14.zip`，默认控制台端口 `5800`；游戏端版本仍为 Bukkit `0.5.3`、Forge / NeoForge / Fabric `0.1.1`。

附件提供字节相同的 `StarBridge-*` 兼容副本和 `SHA256SUMS.txt`，支持现有升级器。

验证：桌面与手机、明暗主题四种组合通过指令路径、复制用法、独立问答编辑器、匹配与未匹配、重复和空草稿、改名删除、真实保存与重新加载检查；HTML、CQ 码与模板变量保持文字，预览不发送写请求或改变未保存状态。JSON 导入保留作者与版本，团队访问边界通过；无脚本、控制台或接口错误。部署包、兼容副本和旧升级器清单完成校验。
