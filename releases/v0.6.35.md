# VexBot v0.6.35

在内置控制台「扩展」中加入插件市场，可浏览随软件分发的精选消息规则，并安装到当前实例。

- 支持关键词搜索、分类和安装状态筛选，插件详情展示触发命令、能力、版本及更新说明。
- 插件可直接安装，完成后到「插件管理」调整设置、确认权限并启用；新装与更新均保持停用。
- 提供目录版本更新，保留兼容设置、权限与旧版本回退记录；本地修改及不可比较版本不会直接覆盖。
- 安装遵循管理权限、目录和包摘要校验、状态版本校验与现有插件数量限制。目录本机可用，无新增外部依赖。
- 适配明暗主题、手机布局和现有动画开关，保留 JSON 插件导入方式。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.35.zip`、内容相同的 `StarBridge-Windows-0.6.35.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。
