# Myrinbot 0.6.11

管理控制台改为统一使用用户名和密码登录，服主与团队成员通过各自账号进入面板。

- 登录页直接显示“用户名”和“密码”，移除登录方式选择及日常管理令牌输入。
- 首次使用通过独立的初始化流程创建服主账号；创建时需使用本机 `config.toml` 中的管理令牌验证授权。已有团队账号可继续使用。
- 服主密码采用加盐哈希保存，登录后使用限时会话；服主拥有完整管理权限，团队账号继续受各自权限限制。退出会撤销当前会话。
- 保留管理令牌的 API 兼容性。备份恢复支持已有数据库，并撤销恢复前的登录会话。
- 更新 Windows 启动检测、启动提示和安装使用文档。控制台默认端口仍为 `5800`。

Windows 部署包为 `Myrinbot-Windows-0.6.11.zip`；已有实例可在面板“设置 → 更新与回退”升级。游戏端版本继续使用 Bukkit `0.5.3`、Forge / NeoForge / Fabric `0.1.1`。

发布附件继续提供字节相同的 `StarBridge-*` 兼容副本及 `SHA256SUMS.txt`，部署包保持旧升级器所需的根目录与受管理路径。

验证：Python 280 项回归通过，包括新增的服主初始化、会话与备份兼容测试；服主及团队登录、权限限制、退出和配置保存浏览器检查通过；25 个面板的桌面与手机检查、明暗主题检查及无确认刷新检查通过；部署包、25 个复用游戏 JAR、兼容副本及旧升级器清单校验通过。
