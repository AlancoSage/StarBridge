# StarBridge 0.6.0

当前项目已按 [AGPL-3.0-or-later](https://github.com/AlancoSage/StarBridge/blob/main/LICENSE) 公开开源，可直接访问 [本版本源码](https://github.com/AlancoSage/StarBridge/tree/v0.6.0) 和 [公开 Release](https://github.com/AlancoSage/StarBridge/releases/tag/v0.6.0)。下文保留发布时的功能、分发方式及验证记录。

- 连接诊断、部署配置导入导出和模板。
- 玩家工单、处罚申诉、跨服处罚与逐服执行确认。
- 监督进程升级、升级前备份、失败恢复和历史回退。
- 白名单申请、工单与申诉、跨服处罚的集中功能开关。

支持完整部署或在更新面板上传 ZIP。包含 Minecraft 桥接插件 0.5.0 和独立官网部署包。
