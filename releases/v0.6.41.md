# VexBot v0.6.41

新增强制绑定：服主可在「成员 → 账号绑定」按服务器要求玩家先绑定 QQ，再连接游戏。

- 默认关闭，独立保存；按本服游戏 UUID 核对绑定，同名或其他服务器的绑定不能放行。
- Paper / Spigot / Folia 游戏插件 0.5.6 在异步预登录阶段检查，未绑定会显示自定义提示与实际 UUID，供管理员核实后建立绑定。
- 每次连接重新检查，解绑后下次连接被拒绝；白名单、封禁和原有游戏登录继续生效，当前在线玩家不会自动被踢出。
- 准入请求使用有界队列与超时，保持主线程和 Folia 实体调度独立；检查服务不可用时，已开启或策略未知的连接拒绝进入。
- 只有在线且上报准入能力的游戏端才允许首次开启；旧插件及当前 Forge / NeoForge / Fabric 模组不支持此入服前检查。
- 设置支持版本冲突检测、便携备份和恢复，普通团队管理员不能修改准入政策。

Bukkit 插件更新至 **0.5.6**，需要替换游戏服务器 JAR 并重启后启用；只升级 Bot 不会让旧游戏端具备拦截能力。Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.41.zip`、内容相同的 `StarBridge-Windows-0.6.41.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。

新整包中的升级监督器已将强制绑定设置纳入回滚清单。历史安装的监督器按原规则受保护，在线更新不会覆盖；如需该版本的完整回滚清单，请保留配置与数据并使用完整部署包更新启动器。便携备份会包含强制绑定设置。
