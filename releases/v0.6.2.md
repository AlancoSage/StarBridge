# StarBridge 0.6.2

- 新增 Forge 1.20.1 服务端模组 0.1.0，支持 Forge 47.x / Java 17。
- 接入 QQ 聊天、进退服、在线状态、玩家档案、绑定码、管理操作、白名单申请及跨服处罚。
- 内置登录支持游戏外注册密码、`/login` / `/l`、`/qqlogin` / `/ql` 和 `/logout`。
- 登录前的数据包保护覆盖移动、背包与模组交互；网络请求在后台执行，连接 nonce 防止旧确认放行重连玩家。
- Bot 面板新增 Forge 模组、配置与安装文档下载，保留 Paper / Spigot 游戏端。
- 自动发布包新增 Forge JAR 及 SHA-256 校验信息；安装说明区分 mods 与 plugins。
