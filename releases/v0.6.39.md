# VexBot v0.6.39

将动画开关移至控制台设置的「界面偏好」，使用与其他设置一致的开关样式。

- 顶栏和登录页不再显示动画按钮。
- 保留原有浏览器偏好，未手动选择时继续跟随系统的减少动态效果设置。
- 动画调整立即生效，无需保存全部设置，不产生主配置草稿，也不影响已有未保存更改。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.39.zip`、内容相同的 `StarBridge-Windows-0.6.39.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。
