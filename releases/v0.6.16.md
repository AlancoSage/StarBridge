# Myrinbot 0.6.16

修复管理面板在未修改配置时显示“有尚未保存的更改”的问题。

- 主配置草稿改为与最近一次载入或保存的内容比较；输入相同内容、修改后恢复原值，不再留下错误的未保存状态。
- 多个字段分别恢复时，仍有实际变更就保留提醒；真正的配置编辑、未填完整或重名的指令仍作为未保存草稿处理。
- 搜索、筛选、密钥显示、独立功能表单及下载插件配置的临时地址，不会触发主配置保存栏。
- 临时新增后移除服务器或指令，会恢复原来的保存状态；保存、重新载入后按最新内容继续比较。

验证：在隔离浏览器中用旧版脚本复现相同输入导致的误报；新版通过桌面 / 手机、明 / 暗主题四组实际操作，覆盖值还原、复选框、官机切换、管理员和关联群分隔符、无效 / 重名指令、临时服务器、搜索与独立表单、保存 / 载入 / 退出。未更改场景没有配置写入，浏览器无 JavaScript 或资源请求错误。17 项发布检查通过；部署 ZIP、25 个游戏 JAR、54 条 SHA256 记录及旧升级器兼容附件均通过校验。本机 5800 面板验证相同输入保持已保存、恢复原值清除提醒，实际配置与插件设置未改变。

控制台默认端口仍为 `5800`。游戏端继续使用 Bukkit `0.5.3`、Forge / NeoForge / Fabric `0.1.1`；同时提供字节相同的 `StarBridge-*` 兼容附件与 `SHA256SUMS.txt`。
