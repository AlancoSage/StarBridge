# Myrinbot 0.6.26

新增可选 MySQL 数据存储。已有安装仍使用 SQLite，不会自动切换或迁移数据。

- 「系统 → 软件设置」可选择 SQLite / MySQL，配置连接、超时、TLS 与 CA 证书，并在保存前检测连接。
- 支持 MySQL 8.0.17+ / 8.4，业务数据直接持久化至 MySQL；账号唯一性、事务与身份标识保持原有规则。连接失败不会自动切换数据库或重放写入。
- 新增离线 SQLite ↔ MySQL 迁移工具，默认拒绝覆盖已有目标，先保存安全副本、核对数据，再切换配置。迁移后撤销临时会话、验证码、密码找回授权及待执行操作。
- MySQL 继续使用现有 ZIP 备份格式与 SQLite 便携快照，恢复保留本机数据库连接。升级监督进程增加 MySQL 快照与恢复支持，禁止直接回退到不支持 MySQL 的版本。
- 配置导出隐藏数据库密码，模板导入保留本机连接；数据库请求失败返回统一提示。

使用与迁移步骤见 [MySQL 文档](https://github.com/AlancoSage/StarBridge/blob/main/docs/mysql.md)。从旧版在线升级后，首次启用 MySQL 前请完全退出软件，再通过启动脚本重新启动。

本次 Bot 更新至 0.6.26；Bukkit 0.5.4、Velocity 0.1.0、Forge / NeoForge / Fabric 0.1.1 保持不变。部署 ZIP、官网 ZIP、全部游戏端附件及旧升级器兼容副本一并提供，使用 SHA256SUMS.txt 校验。

验证：现有 SQLite 回归、94 项真实 MySQL 8.4.7 业务合同、18 项数据库适配测试、11 项迁移与备份测试通过；另验证新用户首次认证、TLS 证书校验及桌面 / 手机设置页面。运行依赖锁定 PyMySQL 1.1.3。
