# Myrinbot 0.6.17

新增指定指令图片回复，在「自动化 → 消息与事件」启用并填写指令名单后，将对应群回复本地排版为中文 PNG；其他回复继续使用文字。

- 支持基础指令、预设控制台指令及其执行结果、扩展指令和关键词回复；保留原有管理员、关联群与插件权限。
- 提供常用指令快捷添加和只预览、不发送的排版入口；预览不影响主配置的未保存状态。
- 本地中文字体、自动换行和分页；OneBot 发送内存图片，QQ 官机使用文件上传与富媒体引用，沿用消息引用、序号与主动发送限制。
- 渲染失败或首图被明确拒绝时回退文字；网络结果不确定、部分页面已送达时不重放。配置或接入切换会停止旧回复及后续分页。
- 固定 Pillow 12.3.0，嵌入未修改的 OFL 中文字体并附完整许可，无需外部图床、浏览器引擎或新的公开回调。

使用步骤及边界见 [指定指令图片回复](https://github.com/AlancoSage/StarBridge/blob/main/docs/image-replies.md)。QQ 官机需要平台图片权限、有效回复上下文或主动发送权限；本版本没有使用真实 QQ 账号或腾讯应用实测图片投递。

验证：完整 Python 回归 319 项通过，图片专项 16 项、官机专项 23 项通过；桌面 / 手机、明 / 暗主题四组配置、分页预览、保存、指令匹配、模拟官机上传发送及关闭后恢复文字均通过，浏览器无 JavaScript 或资源请求错误。部署包、字体和依赖、旧升级器兼容清单、25 个游戏 JAR、54 条 SHA256 记录与兼容附件校验通过；本机 5800 面板预览通过，实际配置和插件设置未改变。

控制台默认端口 `5800`。游戏端继续使用 Bukkit `0.5.3`、Forge / NeoForge / Fabric `0.1.1`；同时提供字节相同的 `StarBridge-*` 兼容附件和 `SHA256SUMS.txt`。
