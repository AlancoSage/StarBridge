# VexBot 0.6.28

项目正式更名为 **VexBot**，同步更新管理面板、官网、机器人回复、图片标题、安装窗口、使用文档和下载附件。面板与官网改用同一枚黑白 V 形机器人图标。

- 源码提供 `VexBot.bat`，原安装入口继续可用。
- 新附件以 `VexBot-*` 命名，仍提供旧升级器需要的 `StarBridge-*` 兼容副本和 SHA256SUMS.txt。
- 网站 SDK 新增 `createVexBotClient` / `createVexBotRegistration`，保留各旧名称导出。
- 升级不改变现有账号、绑定、数据库连接、服务器配置、API 路径或游戏插件身份。

本次重新构建 Bukkit **0.5.5**、Velocity **0.1.1** 与 Forge / NeoForge / Fabric **0.1.2** 全部游戏端，显示与日志使用 VexBot。旧正式 Release 和历史附件保留。

命名与兼容路径的详细说明见 [项目名称与兼容说明](https://github.com/AlancoSage/StarBridge/blob/main/docs/project-name.md)。

验证：Python 全量检查完成 523 项（414 通过，109 项按环境条件跳过）；全部 26 款游戏端重新构建并通过现有协议与安全回归，面板、官网、图标、在线图片及手机布局通过浏览器检查，部署包通过旧升级器协议和 SHA256 校验。
