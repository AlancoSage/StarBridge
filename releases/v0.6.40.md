# VexBot v0.6.40

统一控制台滚动条外观，让页面、下拉菜单和弹窗与现有主题保持一致。

- 使用细圆角滑块与透明轨道，悬停和拖动时加强提示，自动适配明暗主题。
- 保留原生滚轮、拖动、键盘和触摸操作；高对比度模式继续使用系统滚动条。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.40.zip`、内容相同的 `StarBridge-Windows-0.6.40.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。
