# Myrinbot v0.6.23

指定指令的图片回复进一步贴近最初参考图：背景根据用户参考图清除文字与界面后重建，卡片采用轻模糊、高透光玻璃与细白边；标题、在线人数框、三项统计和玩家标签按参考图归一到 1080 像素宽，修正之前卡片偏高、徽章和玩家标签过宽的问题。文字改用真正的 Noto Sans SC Bold 粗体与轻阴影。

- 「在线」卡片只保留服务器名、在线人数和玩家标签，去掉容量、版本及空服副行；「状态」仍展示容量、版本和离线提示。
- 玩家标签改用按名字在本地确定生成的像素头像，不是真实 Minecraft 皮肤，不请求第三方头像服务。字体和背景随包内置，既有开关和指定指令名单继续生效，无须新增配置。
- 「在线」「状态」继续只使用当前群关联服务器的真实数据，离线时隐藏过期玩家；面板预览可选择已保存服务器，默认仍使用示例文字。
- 支持长名单分页，每次最多四页，每页 PNG 不超过 2 MiB；超出边界仍按现有规则回退文字。预览不会保存配置、发送 QQ 或触发未保存提示。

验证范围包括中文与粗体渲染、分页与大小边界、离线数据、群隔离与预览权限、草稿状态、OneBot 消息段和 QQ 官机模拟图片上传。未使用真实 QQ 账号或腾讯应用实测投递，部署后仍需按应用权限验收。

完整部署包为 `Myrinbot-Windows-0.6.23.zip`，独立官网包为 `Myrinbot-website.zip`。保留内容相同的 `StarBridge-*` 兼容附件及 `SHA256SUMS.txt`，供现有升级器使用。Bukkit 插件仍为 0.5.3，Forge / NeoForge / Fabric 模组仍为 0.1.1。
