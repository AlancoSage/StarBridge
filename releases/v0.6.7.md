# StarBridge 0.6.7

- 新增 NeoForge 1.20.6 独立服务端模组，固定正式构建 NeoForge 20.6.141，游戏服使用 Java 21，文件为 `StarBridge-NeoForge-1.20.6-0.1.0.jar`。
- 1.20.6 使用 UTF-8 `config/starbridge-bridge.properties`；面板提供独立版本选择、正确的 Java 要求、连接配置与 JAR 下载。接入 QQ 聊天、在线状态、玩家档案、白名单、管理回执以及 `/l`、`/ql`、`/qbind`、`/logout`。
- 保留已有七个 NeoForge、六个 Forge、十个 Fabric 与通用 Paper / Spigot 游戏端。此次共有二十四个模组 JAR，完整私有 Release 提供二十八个附件。
- 原生绑定按 1.20.6 的官方服务端类和成员签名验证，强制启用全部登录保护 Mixin。构建使用 JDK 17，游戏服按 Java 21 运行；原 NeoForge 1.21.1 的 Gradle 构建与 TOML 配置保持。
- 历史发布仍按该版本自己的源码 catalog 构建；0.6.6 保持二十三个模组，不会混入 1.20.6。
- NeoForge 1.20.6 完成 23 项实服检查：真实 TCP、Minecraft 原生 `ProtocolInfo` / `StreamCodec`、离线 signed 命令与 ACK，协议解码错误为 0；包括注册表、配方与背包同步。测试使用隔离 Bot 和模拟 QQ，不代表正版签名链或全部整合包组合。
- 249 项 Python 测试及无 GPU 面板检查通过；所有 24 个 JAR 可按版本下载，连接配置、Java 要求与五种屏幕宽度均已核对。
