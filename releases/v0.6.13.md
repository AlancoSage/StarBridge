# Myrinbot 0.6.13

补齐远程命令页的新建入口，让首次配置指令时可以直接找到操作位置。

- 页面顶部始终显示「＋ 新建指令」按钮；只有一台服务器时直接生成空白指令草稿，多台服务器时先选择目标服务器。
- 尚未添加服务器时，通过「前往添加服务器」进入「接入空间 → 服务器列表」，添加并保存服务器后再配置命令；尚无命令时，显示新建指令的操作提示。
- 保留服务器卡片的「＋ 添加命令」和命令卡片的移除按钮。填写群内命令名与固定控制台命令后，点击「保存全部设置」使新增或删除生效。

Windows 部署包为 `Myrinbot-Windows-0.6.13.zip`。用户名和密码登录方式、默认 `5800` 端口及游戏端版本保持兼容：Bukkit `0.5.3`，Forge / NeoForge / Fabric `0.1.1`。

发布附件继续提供字节相同的 `StarBridge-*` 兼容副本和 `SHA256SUMS.txt`，可通过现有控制台升级。

验证：桌面、手机与明暗主题四种组合下，通过无服务器引导、单服直接新建、多服选择与取消、搜索空状态、指令增删保存并重新加载，以及服务器改名和删除检查；无脚本、控制台或接口错误。本机新建按钮显示、部署包、兼容副本、校验清单与旧升级器清单均通过校验。
