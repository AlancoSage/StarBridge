# StarBridge 0.6.5

- 新增 Fabric 1.21.8、1.21.11、26.1、26.2 和 26.3 服务端模组，保留原来的五个 Fabric 版本，以及 Paper / Spigot、Forge 和 NeoForge 游戏端。
- Fabric 新增五版使用 Loader 0.19.5；1.21.8 / 1.21.11 使用 Java 21，26.1–26.3 使用 Java 25。星桥自身仍无需 Fabric API 或客户端模组。
- 新版接入同一套 QQ 聊天、在线状态、玩家管理、白名单和账号认证流程，支持 `/l`、`/ql`、`/qbind` 与 `/logout`。
- 1.21.8 / 1.21.11 使用各自固定 Yarn 映射；26.x 直接访问官方非混淆类名，构建时逐项校验实际类、成员和签名。构建环境仍为 JDK 17，星桥公共引擎输出 Java 8 字节码；游戏服按自身要求运行。
- 管理面板增加新版本 JAR 与 UTF-8 properties 配置下载，显示 Java 要求并提供十版 Fabric 安装指南。
- 私有发布自动构建并校验十七个模组游戏端，核对 Minecraft、Loader、Java、映射命名空间和强制保护 Mixin；历史版本继续按自身目录打包，不增加历史发布附件。
- 更新 Windows / Linux 游戏端构建说明、Java 选择与交叉文档。实际验证范围和部署限制见 Fabric 安装指南。
- 新增五版均完成真实专用测试服验证：1.21.8 / 1.21.11 / 26.1 各 21 项，26.2 / 26.3 各 23 项；后两版使用对应官方协议编解码完成真实 TCP 登录与联动。233 项自动测试通过；测试采用离线模式与模拟 QQ，不代表已验证正版账号签名链或所有整合包。
