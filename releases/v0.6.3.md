# StarBridge 0.6.3

- 新增 Forge 1.7.10、1.12.2、1.16.5、1.18.2、1.19.2 游戏端，保留 Forge 1.20.1，并提供 NeoForge 1.21.1。
- 各版本均支持 QQ 联动、在线状态、玩家管理、白名单、绑定及注册密码 / QQ 确认登录，含 `/l`、`/ql`。
- 旧版使用 Java 8，Forge 1.18.2–1.20.1 使用 Java 17，NeoForge 1.21.1 使用 Java 21；均为独立服务端模组。
- 面板新增版本选择、对应 JAR 和配置下载；旧版 properties 与新版 TOML 自动区分。
- 发布流程自动构建全部游戏端并校验元数据与 Java 字节码，部署包携带七种模组，独立附件包含 SHA-256 校验文件。
- 增加多版本安装、升级、排查及开发构建文档。已在指定加载器的真实专用服务器上验证登录和管理流程；其他构建号及整合包组合仍需自行联调。
