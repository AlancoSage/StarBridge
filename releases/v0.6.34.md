# VexBot v0.6.34

统一内置管理面板及共用注册、密码找回页面的表单校验提示，使其与页面明暗主题保持一致。

- 必填、格式和数值范围错误改为字段旁的中文提示，搭配错误边框；提交时定位到首个错误字段，修正后自动清除提示。
- 保留原有 HTML 表单约束与业务检查，有错误时不会提交。提示与字段关联，兼顾键盘操作及窄屏阅读。
- 错误提示遵循面板的动画偏好及减少动态效果设置。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.34.zip`、内容相同的 `StarBridge-Windows-0.6.34.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。
