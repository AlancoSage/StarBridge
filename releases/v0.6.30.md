# VexBot v0.6.30

补齐新版 WebUI 控制台的启动、登录和网站详细设置文档，并将说明随 Bot 部署包分发。

- 新增新版控制台使用指南，区分 5800 内置管理面板、5801 独立 React 控制台与 8089 社区官网本机预览，提供启动、构建、后台代理配置和故障处理步骤。
- 明确新版控制台的玩家管理与网站详细设置读写真实后台；运行总览、服务器、指令中心和其余预览选项仍使用示例数据。独立前端源码不包含在 Bot 部署包中。
- 补充统一管理员登录、服主和玩家管理权限、三种网站接入方式、独立保存、并发冲突处理、公开 API 检查与接入文件下载说明。
- 更新主说明、快速开始、面板与玩家指南、官网部署、更新回退及开发贡献入口，并修正玩家档案支持可选 MySQL 的说明。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.30.zip`、内容相同的 `StarBridge-Windows-0.6.30.zip`、配套游戏端和官网附件及 `SHA256SUMS.txt`，保留现有升级协议。
