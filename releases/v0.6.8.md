# StarBridge 0.6.8

> 本项目现名 **Myrinbot**。本页为历史版本说明，附件名称、命令和版本信息保留发布时记录。

当前项目已按 [AGPL-3.0-or-later](https://github.com/AlancoSage/StarBridge/blob/main/LICENSE) 公开开源，可直接访问 [本版本源码](https://github.com/AlancoSage/StarBridge/tree/v0.6.8) 和 [公开 Release](https://github.com/AlancoSage/StarBridge/releases/tag/v0.6.8)。下文保留发布时的功能、分发方式及验证记录。

- 通用游戏插件升级为 `StarBridge-0.5.1.jar`，新增 Folia 全局与玩家实体调度适配，Paper / Spigot / Folia 共用同一个 Java 8 字节码 JAR；游戏服 Java 仍按核心要求选择。
- Folia 玩家档案按所属区域采集，聊天广播、绑定码、密码 `/l`、QQ `/ql`、退出登录和踢出回到玩家实体线程；白名单、档案封禁与任务回执在全局调度处理。连接退休、异步旧结果和停服时取消任务并清理引用，调度失败不误报广播成功。
- 管理处罚自动解封时同时核对封禁来源 `StarBridge` 与原处罚原因；来源不符、原因已变更或核心无法校验时保留封禁并返回失败，避免解除管理员独立设置的封禁。
- Folia 游戏登录使用「星桥内置」或「自动」引擎；已启用 AuthMe 或选择 AuthMe 引擎时拒绝放行。Paper / Spigot 的可选 AuthMe API v3 接入保持可用。认证插件安装、升级与移除使用完整停服重启。
- 面板下载按钮、服务器安装提示与使用文档加入 Folia，连接配置保持 `plugins/StarBridge/config.yml`。二十四个 Forge / NeoForge / Fabric 模组 JAR 与官网独立部署方式保持；私有 Release 提供二十八个附件。
- Bukkit 与 Folia 调度各完成 25 项隔离检查，验证公开接口反射、任务拒绝、退休、重复调用与停用竞态；不将隔离接口测试等同于所有 Folia 构建号的实服验证。
- Folia 内置登录完成 27 项隔离检查，覆盖双区域密码 / QQ、即时策略失效、连接 nonce、后台重建、晚到的退出事件、超时、AuthMe 拒绝与停用竞态；新测试脚本独立编译当前源码，不改写正式 JAR。
- 官方 Folia 1.21.8 正式 build 6 / Java 21 完成 35 项实服检查：4 个区域线程、两名相隔 8192 格的玩家，验证密码 / QQ 登录、操作限制、跨区域广播与档案、白名单、带来源校验的处罚和在线玩家正常停服；心跳全部接受、客户端解码错误为 0、停服退出码为 0。本轮使用离线 Minecraft 协议客户端和隔离 OneBot 接口，未验证正版档案签名链、真实 QQ 发送或其他 Folia 构建号。
