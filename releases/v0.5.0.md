# StarBridge 0.5.0

当前项目已按 [AGPL-3.0-or-later](https://github.com/AlancoSage/StarBridge/blob/main/LICENSE) 公开开源，可直接访问 [本版本源码](https://github.com/AlancoSage/StarBridge/tree/v0.5.0) 和 [公开 Release](https://github.com/AlancoSage/StarBridge/releases/tag/v0.5.0)。下文保留发布时的功能、分发方式及验证记录。

历史 Bot 版本，来自 Git 中最后一个 0.5.0 提交，补建发布记录。

- QQ 与 Minecraft 联动、网页管理面板、玩家及账号管理。
- 插件、定时任务、白名单、备份与恢复和独立官网。
- 包含 Java 8 通用 Minecraft 桥接插件 0.5.0。

此版本尚无面板自动更新协议，需要手动安装。请优先部署最新正式版。附件不包含真实配置、数据库或私密令牌。
