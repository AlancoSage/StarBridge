# Myrinbot 0.6.25

修复多个玩家同时申请原生密码找回时，一批下发任务可能超过 Bukkit 找回端上限的问题。每批最多下发 8 项，其余请求等待下一次心跳，防止任务被游戏端整批拒绝。

保留 0.6.24 的 AuthMe、LimboAuth、LibreLogin 兼容、私聊双向绑定证明、原生账号代次校验、离线重置、二次验证保留和一次性执行机制。

配套 Bukkit 插件仍为 0.5.4，Velocity 插件为 0.1.0，Forge / NeoForge / Fabric 模组为 0.1.1。提供完整 Windows 部署包、独立官网、全部游戏端附件、旧升级器兼容附件和 SHA256SUMS。v0.6.24 保留原附件，不覆盖。
