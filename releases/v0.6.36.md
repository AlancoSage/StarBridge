# VexBot v0.6.36

内置控制台「活动 → 运行日志」升级为实时终端式日志，汇总当前进程的程序日志、异常堆栈与业务记录。

- 支持等级着色、来源及关键词筛选，暂停与继续、跟随底部、字号与换行、全屏阅读、复制及下载当前筛选结果。
- 可见日志页每秒增量读取，离开页面或后台暂停请求；上翻阅读时保持位置，网络异常退避重试，登录失效和权限不足停止请求。
- 当前进程使用 1000 条有界缓存，启动载入最近 200 条业务记录；识别缓存截断及服务重启。清空仅作用于浏览器视图。
- 日志接口沿用服主权限，对已识别的凭据脱敏；不改变数据库结构、Python 日志级别或原有输出。
- 适配明暗主题、手机布局和现有动画开关。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.36.zip`、内容相同的 `StarBridge-Windows-0.6.36.zip`、配套游戏端和官网附件，共 57 个附件；其中 `SHA256SUMS.txt` 列出其余附件的 SHA256，保留现有升级协议。
