# VexBot v0.6.29

新增可选的智简魔方财务机器人模块。使用现有 Python / OneBot 11 接入，在私聊中验证并绑定用户自己的服务商 API 账号后，查询一级、二级商品分组和商品详情，获取报价、确认下单，并返回付款二维码或链接。

- 多服务商通过与 `config.toml` 同目录的 `billing.toml` 配置，默认关闭；仅使用财务私聊时不需要 Minecraft 游戏端。
- API 凭据和待确认商品参数使用独立 Fernet 密钥加密，订单和确认码使用独立 SQLite 持久化，按用户、服务商和账号绑定代次隔离。
- 下单确认有效期 5 分钟，确认时重新报价，只结算本次加入的购物车位置。重复消息、确认重放与结果不确定的请求不会自动重复创建订单。
- 支持查询本人订单与重新获取付款入口；二维码在本机生成，支付插件 HTML 返回服务商账单页面。
- 新增财务功能专项测试，覆盖绑定、分组商品、指定购物车结算、跨账号隔离、确认重放和支付回复。真实服务商下单、付款到账及交付仍需部署后联调。

部署和指令示例见 [魔方财务接入说明](https://github.com/AlancoSage/StarBridge/blob/main/docs/mofang-billing.md)。现有面板便携备份不包含独立财务数据库，请按文档一起备份 `billing.toml`、`data/billing.sqlite3` 与 `data/billing.key`。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。发布已重新构建 Bot 部署包，并校验完整附件、兼容更新 ZIP 与 SHA-256 清单。
