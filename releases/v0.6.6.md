# StarBridge 0.6.6

当前项目已按 [AGPL-3.0-or-later](https://github.com/AlancoSage/StarBridge/blob/main/LICENSE) 公开开源，可直接访问 [本版本源码](https://github.com/AlancoSage/StarBridge/tree/v0.6.6) 和 [公开 Release](https://github.com/AlancoSage/StarBridge/releases/tag/v0.6.6)。下文保留发布时的功能、分发方式及验证记录。

- 新增 NeoForge 1.20.4、1.21.4、1.21.8、1.21.11、26.1.2 与 26.2 六版服务端模组，保留 NeoForge 1.21.1 以及现有 Paper / Spigot、Forge、Fabric 游戏端。NeoForge 仅提供正式构建，不包含 26.3 beta。
- 固定组合为 20.4.251 / Java 17，21.4.158、21.8.54、21.11.45 / Java 21，26.1.2.114、26.2.0.88 / Java 25。Minecraft 26.1.2 与 26.1 分别使用各自安装器与 JAR，不能跨版本替换。
- 新增版本接入相同的 QQ 聊天、在线状态、玩家档案、白名单申请与审核、踢出、封禁和来源保护，以及 `/l`、`/ql`、`/qbind`、`/logout`。
- 新版使用 UTF-8 `config/starbridge-bridge.properties`，已有 NeoForge 1.21.1 继续使用 `config/starbridge-common.toml`，无需迁移配置。面板按所选游戏版本导出对应格式，显示 Java 要求并下载独立 JAR。
- 新版原生绑定在构建时核对游戏类、成员与签名，强制安装登录保护 Mixin。构建环境使用 JDK 17，游戏服按各版本要求运行；原 1.21.1 Gradle 构建继续保留。
- 私有发布自动构建并校验二十三个模组游戏端，核对元数据、Minecraft / NeoForge / Java 版本、核心类、绑定与强制保护 Mixin。历史版本继续按自身 catalog 打包，不增加新附件。
- 更新 Windows / Linux 游戏端构建说明、部署配置与 Java 选择；部署 ZIP 提供现成 JAR，自行编译需要私有仓库的完整源码。实际验证范围见模组安装指南。
- 六个新增 NeoForge 版本均完成隔离实服验证：1.20.4 / 1.21.4 / 1.21.8 / 1.21.11 各通过 21 项，26.1.2 / 26.2 各通过 23 项；测试使用真实 TCP、离线账号和模拟 QQ，不代表所有整合包、真实 QQ 或正版签名链。248 项 Python 测试及无 GPU 面板检查通过。
