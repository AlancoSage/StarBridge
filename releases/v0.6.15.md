# Myrinbot 0.6.15

新增可选 QQ 官方机器人接入，通过 AppID / AppSecret 和官方 WebSocket Gateway 连接，保留现有 OneBot 11 接入。

- 管理面板新增接入方式选择、AppID / AppSecret、官机管理员和主动发送开关；显示真实接入状态与安全的错误提示。
- 支持访问凭证缓存与刷新、网关心跳和重连恢复，接收群 @消息与 C2C 单聊事件，按官方消息引用发送文字回复。
- 官机群与用户身份按 AppID 和场景隔离，可关联游戏服务器、验证码绑定与解绑、查询状态、执行预设指令、处理 JSON 消息规则与白名单申请。
- 部署导出隐藏官机密钥，配置导入保留本机接入信息；接入变化会撤销旧群内远程任务。官机的普通群消息、群管理、QQ 邮箱与主动发送限制在面板和文档中说明。
- 故障提醒群设置接受官机群身份，仍按有效回复上下文和平台权限发送。

支持范围及上线步骤见 [QQ 官机接入](https://github.com/AlancoSage/StarBridge/blob/main/docs/qq-official.md)。此版本使用 WebSocket 接入，不包含 Webhook、频道或富媒体发送；未用真实腾讯应用完成平台实测。

Windows 包为 `Myrinbot-Windows-0.6.15.zip`，控制台默认端口 `5800`。游戏端继续使用 Bukkit `0.5.3`、Forge / NeoForge / Fabric `0.1.1`；发布字节相同的 `StarBridge-*` 兼容附件和 `SHA256SUMS.txt`。

验证：完整 Python 回归 298 项通过（含官机协议、身份、权限与配置检查 18 项）；桌面 / 手机、明 / 暗主题的官机设置保存、模拟 Gateway 与 REST 收发、密钥变更重连和接入切换通过；25 个面板页面在桌面和手机端通过，无 JavaScript 或资源请求错误。本机 5800 面板只读检查通过，未修改实际接入配置。部署 ZIP、25 个游戏 JAR、54 条 SHA256 校验记录、字节相同的兼容附件及旧升级器清单均通过校验。
