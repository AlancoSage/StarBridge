# VexBot v0.6.31

调整内置管理控制台左侧导航的间距，让分组与子页面的层级更清楚。

- 统一顶级菜单的行高和分组间距，收紧展开后的子菜单，避免多处外边距叠加造成空隙不一致。
- 子菜单文字与所属分组的文字对齐，统一选中背景、图标和计数的位置。
- 桌面收起侧栏时保持图标等距；手机导航保留 44px 触摸区域与原有展开、滚动操作。

Bukkit 插件保持 0.5.5、Velocity 密码找回插件保持 0.1.1，Forge / NeoForge / Fabric 模组保持 0.1.2。正式 Release 提供完整 `VexBot-Windows-0.6.31.zip`、内容相同的 `StarBridge-Windows-0.6.31.zip`、配套游戏端和官网附件及 `SHA256SUMS.txt`，保留现有升级协议。
