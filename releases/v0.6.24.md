# Myrinbot 0.6.24

增加已绑定 QQ 的原登录插件密码找回，默认关闭。支持 AuthMe（Bukkit）、LibreLogin（Paper / Velocity）和 LimboAuth（Velocity）；按本次要求不接入 EasyAuth。

- 面板「成员 → 游戏登录」按服务器选择原生密码找回端。OneBot 玩家先经过原插件认证并执行 `/qbind`，用自己的 QQ 私聊 `/验证绑定 服务器ID 验证码`，以后可私聊 `/重置密码 服务器ID`，确认后更新自己的游戏密码。
- 新密码只短暂存在内存中，不写入普通任务、数据库、日志或备份。一次性下发和执行前认领检查防止重放；解绑、更改配置或接入身份后撤销未开始的请求。
- 游戏端只修改离线账号，核对 UUID、玩家名和原账号创建信息，保留二次验证。旧绑定需重新 `/qbind` 并用原 QQ 私聊确认验证码，无需解绑；群绑定不会自动获得改密权限。AuthMe 需关闭原生 IP 会话登录。
- 增加独立的 Velocity 配套插件 0.1.0；Bukkit 插件更新为 0.5.4，Forge / NeoForge / Fabric 模组继续为 0.1.1。
- 备份包含找回设置，恢复后撤销原生找回权限，兼容没有新增表的旧备份。
- 修复 QQ 官机关闭恰好遇到心跳清理时可能吞掉取消信号、继续重连的问题。

QQ 官机群与私聊 OpenID 不可直接关联，此项找回暂仅支持 OneBot。Folia 原生登录插件、多代理共享账号数据库不在本次范围。

提供完整 Windows 部署包、独立官网、Bukkit / Velocity / Forge / NeoForge / Fabric 附件，以及内容相同的旧升级器兼容附件与 SHA256SUMS。原版本附件保持不变。
