# Myrinbot v0.6.18

指定指令的图片回复换用原创冬日插画、毛玻璃卡片和白色大标题。「在线」「状态」按当前群关联的服务器生成真实在线统计与玩家名单，离线时隐藏过期玩家；其他已选指令使用同风格文字卡片。现有开关和指令名单继续生效，无需新增配置。

- 面板排版预览可以选择已保存服务器；仅「在线」「状态」采用所选服务器的实际数据，默认仍使用示例文字。预览不会保存配置、发送 QQ 或触发未保存提示。
- 玩家标签使用本地名字首字头像，不依赖第三方头像服务。背景和中文字体均随程序内置。
- 支持长名单分页，每次最多四页，每页 PNG 不超过 2 MiB；超出边界仍按现有规则回退文字。群关联或接入配置在渲染期间改变时，停止发送旧回复。

验证包括中文渲染与分页、离线数据、群隔离与预览权限、草稿状态、OneBot 消息段和 QQ 官机模拟图片上传。未使用真实 QQ 账号或腾讯应用实测投递，部署后仍需按应用权限验收。

完整部署包为 `Myrinbot-Windows-0.6.18.zip`，独立官网包为 `Myrinbot-website.zip`。保留内容相同的 `StarBridge-*` 兼容附件及 `SHA256SUMS.txt`，供现有升级器使用。Bukkit 插件仍为 0.5.3，Forge / NeoForge / Fabric 模组仍为 0.1.1。
