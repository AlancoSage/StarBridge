# Myrinbot 0.6.10

本版将项目正式更名为 **Myrinbot**，更新管理控制台、官网和全部游戏端的品牌展示，并保持已有账号、配置和升级协议兼容。

- 管理控制台采用黑白明暗主题、分组侧栏、功能搜索和手机导航，统一表单、列表和状态展示。登录页、注册页、密码页、官网与浏览器标签页使用新生成的 M 形机器人图标。
- 新安装的控制台默认地址为 `http://127.0.0.1:5800/`，游戏端新配置也默认连接此端口。升级保留已有 `config.toml` 和游戏端配置；使用自定义端口的实例仍按原配置连接。独立官网的预览端口继续为 `8089`。
- 刷新或关闭控制台时不再弹出浏览器的“系统可能不会保存您所做的更改”确认框。配置仍需点击保存；刷新会丢弃未保存的编辑。
- 通用 Paper / Spigot / Folia 插件更新为 `Myrinbot-0.5.3.jar`；二十四个 Forge、NeoForge、Fabric 游戏模组更新为 `0.1.1`，同步新品牌与 `5800` 默认连接地址。
- 发布主附件使用 `Myrinbot-*` 名称，每个附件同时提供字节相同的 `StarBridge-*` 兼容副本和 `SHA256SUMS.txt`。Bot 部署 ZIP 保留 `StarBridge/` 根目录及原受管理路径，已有面板可检查、下载并安装新版本。
- 推荐源码启动入口为 `Myrinbot.bat`，保留 `星桥.bat`、`云墟.bat` 兼容入口；部署包继续使用 `星桥.bat`。Python 模块 `starbridge`、插件标识、模组 ID、游戏命令命名空间、数据库和插件配置目录保持兼容。
- 官网 SDK 新增 `createMyrinbotClient` 导出，同时保留 `createStarBridgeClient`。教程、下载示例和 API 地址同步新名称与默认端口。

Windows 首次部署可下载 `Myrinbot-Windows-0.6.10.zip`；已有实例可在面板“设置 → 更新与回退”检查升级。游戏 JAR 需分别替换到对应 Minecraft 服务器并重启；每台服务器只安装新名称或兼容名称中的一份。独立部署的官网需单独更新 `Myrinbot-website.zip`。

验证：Python 262 项回归；管理控制台 25 个面板的桌面与手机检查；新图标 16 个显示场景与公开路由检查；25 个游戏 JAR 的构建、版本、默认地址、许可证及兼容副本校验；Bukkit 101 条 API 引用检查及四个 Gradle 构建和测试；完整部署包和旧升级器清单校验。发布先上传草稿并核对全部 55 个附件，再开放正式版本。
